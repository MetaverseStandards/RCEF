# Expression sets

Each file in [profiles/](../profiles) records one public expression set, except `fixture.toml`, which holds RCEF's own synthetic fixtures. This page lists every profile file and where its set comes from. The README's [Mappings](../README.md#mappings) table shows what translates to what.

- **Documentation** is the usual web page for the set.
- **Pinned source** is the exact revision or retrieval that RCEF verified. [references.md](../references.md) and [evidence/sources.toml](../evidence/sources.toml) list it with its SHA-256.
- **Role in maps:** at least one executable mapping reads a **source** set, and at least one writes a **target** set. An **inventory only** set is recorded but not translated yet.

`tests/test_readme_sources.py` checks this table against the profile files, the evidence records and the pack. Edit it by hand when a profile file changes.

## Signal counts

The Signals column counts every inventory row, including count sentinels and rows recorded as absent. So it can be higher than the selected-interface counts in the README section [What RCEF covers](../README.md#what-rcef-covers). FB2 has 70 weights plus `COUNT` (71), FB has 63 plus `COUNT` and an absent tongue row (65), the VRCFT transport enum has 88 plus `Max` (89), and MediaPipe has its 52 labels plus an absent `tongueOut` row (53). Godot blended has 41 shapes plus the `FT_MAX` sentinel (42).

## RCEF's own sets

RCEF's own canonical set, `rcef.canonical` (21 signals), is in [data/canonical.toml](../data/canonical.toml). It is the target of the three `*.to_canonical` maps. The draft canonical expression set, `rcef.canonical_expression` (70 signals), is in [data/canonical_expression.toml](../data/canonical_expression.toml). [canonical-set.md](canonical-set.md) defines it. ARKit, FB2 and FACS codes (`facs.code`) map into it, and it maps to ARKit, FB2, Unified Expressions, VRM blinks and FACS codes. The draft canonical viseme set, `rcef.canonical_viseme` (16 signals: 15 IPA shape classes and the aggregate `alveolar_floor`), is in [data/canonical_viseme.toml](../data/canonical_viseme.toml), and [canonical-set.md](canonical-set.md#visemes) defines it too. META visemes and the VRM vowel presets map into it and out of it. The README's [Mappings](../README.md#mappings) tables list these maps. RCEF's intermediate values, `rcef.intermediate` (65 signals), are in [data/intermediate.toml](../data/intermediate.toml). 8 are the signed difference of two opposing gaze directions: 4 of ARKit's, which `arkit_gaze.to_fb2` computes, and 4 of the canonical expression set's, which `rcef_gaze.to_fb2` computes. The 9th is the sum of META's SS, DD, NN and RR before the clamp, which `visemes_aggregate.to_rcef` computes. The other 56 belong to the [viseme pose bridge](canonical-set.md#viseme-pose-bridge), `rcef_viseme_pose.to_rcef_expression`: each passing viseme class read as the activation of its pose, and each expression signal's sum of poses before the clamp. Each map computes them internally, and no provider reads or writes them.

## Planned expression sets

This section is a plan, not data. It goes with the draft [canonical expression set](canonical-set.md), through which every translation is to run. Phase 1 is the first release of the canonical set. Its sources are ARKit, FB2, META visemes, VRM (blinks and vowels), VRCFaceTracking eye data and FACS codes (`facs.code`); Unified Expressions is a target only.

**Rule for every new set.** A set joins only with a pinned public source and a known licence. It gets a profile, evidence records, rows in the [definitions audit](canonical-set-audit.md), a row in the test that checks which canonical groups each set can fill, and in-maps or out-maps. A new copyright holder of CC-BY-4.0 text gets a row in [THIRD_PARTY_NOTICES.md](../THIRD_PARTY_NOTICES.md). A product name in a profile ID gets a trademark check. New sets join after the first release of the canonical set, so they do not change the comparison with today's maps. A pair of sets with no public route between them is labelled "no external reference".

**How the list was made.** It has RCEF's own profiles; every face, facial, lip and eye-expression weight enum in the OpenXR registry at `5a82d45` (`xr_registry`), so it is complete for OpenXR at that commit; and other sets the authors knew of. It is not a complete list of public sets.
